# 📚 Sistema de Gestão de Biblioteca (Java)

> Aplicação de consola desenvolvida em Java para o controlo de acervo bibliotecário, empréstimos, devoluções e persistência de dados em ficheiros de texto.

---

## 📌 Sobre o Projeto

Desenvolvido para consolidar conceitos avançados do **3º semestre de Análise e Desenvolvimento de Sistemas**, este projeto explora manipulação de coleções, encapsulamento de estados e manipulação de fluxos de E/S (`I/O`) para gravação de registos em disco.

### 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java (JDK 17+)
- **Conceitos Aplicados:**
  - Orientação a Objetos (Classes, Atributos e Métodos de Instância)
  - Gestão de Coleções (`ArrayList`)
  - Tratamento de Exceções (`try-catch`)
  - Persistência de Dados em Ficheiro (`FileWriter`)

---

## 🎯 Funcionalidades

- [x] Registo de novos livros com título e autor.
- [x] Listagem dinâmica do catálogo com estados visuais (Disponível / Emprestado).
- [x] Fluxo de empréstimo e devolução de exemplares.
- [x] Funcionalidade de salvamento automático/manual dos dados em disco (`biblioteca_dados.txt`).
